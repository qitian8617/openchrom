# 白酒 FID 试点演示与验收脚本

厂里现场用这一份勾选：**真混标一针、真样品合格一针、真样品不合格一针**（没有仪器时走脚本 A 软件演示）。勾完签字，即试点清单 **项 16**。

日常怎么点按钮，仍以 [白酒FID试点操作手册.md](白酒FID试点操作手册.md) 为准。本文不替代手册，也不替代工程师回归清单 `demo/回归检查清单.txt`。

英文指针：[GCWS-OPERATOR-MANUAL.md](GCWS-OPERATOR-MANUAL.md)。打印用勾选表：`demo/验收勾选表.txt`。

---

## 1. 目的

让厂工程师 / 验收人在 **白酒 FID 工作站专用壳或已安装 Baijiu FID Pilot 的社区版** 上，按同一套预期把三条路径各跑一遍，并留下通过/不通过记录：

| 路径 | 要证明什么 |
|------|------------|
| 混标校正 | 推荐积分后约 16 峰；甲醇 RF 写入；定量门禁可通过 |
| 样品合格 | 甲醇折算 ≤ 厂方法粮谷（或对应原料）限量 → GB 2757 **合格**，报告字段齐全 |
| 样品不合格 | 甲醇折算 **超过** 该原料限量 → GB 2757 **不合格**（真机用真超标样；无真机用下方 **仅演示** 限量覆盖） |

验收对象是 **软件能否正确校正、定量、判定、出报告**，不是重新开发功能 1～14。

## 2. 范围与不做事项

**本次验收做：**

- 安装与许可已就绪（手册第 2～3 节）前提下的混标 → 定量 → GB 2757 → 报告
- 软件演示（脚本 A）和/或真机三针（脚本 B）
- 许可门、混标 RF 门各至少一条 **负向**（拦住，而不是悄悄出数）
- 不合格路径必须能勾上；软件演示须标明 **仅演示，不是真实批次结果**

**本次验收不做（不要写进结论）：**

- 清单 **项 15**（1～2 家试点驻场）——只在现场发生，本文不代替驻场
- 不声明执行 **GB 5009.266**
- 无 21 CFR Part 11、无 LIMS、无自动进样器控制
- 不改出厂 GB 2757 默认限量（粮谷 **0.6** g/L、其他 **2.0** g/L，100%vol）
- 不把演示 `.ocb` 或临时压低的限量当成真实酒样 / 国标结论
- 不使用 `-Dnet.openchrom.baijiu.skipLicenseGate` 或 `-Dnet.openchrom.gcws.skipFidReadinessGate` 做现场验收

Java 运行时保持 **JavaSE-21**。

## 5. 脚本 A — 软件演示验收（无真机）

用演示 `.ocb`。混标 / 合格样 **不是** 实机进样。不合格走 **仅演示** 临时限量，**不要**另造一条假谱图、也不要改 git 里的出厂 0.6。

### A0. 许可

1. **插件 → 白酒工作台 → 许可 / 版本…** → **导入 *.bjlic…** → `demo/sample-pilot.bjlic`
2. 状态须为 **许可：有效**（示例酒厂 / Pilot Demo / 至 2027-12-31）

- [ ] 许可有效

### A1. 混标校正

1. 打开 `mix-15plus-istd.ocb` → **推荐积分**
2. 2–17 min 约 **16** 个峰，面积不为 0；峰匹配页内标 **乙酸正丁酯**（本机约 10.382 min）已积分
3. **白酒分析** → 确认内标体积/贮备液为默认 → **用当前谱图做校正**
4. **组分方法** 页：甲醇等组分出现本机 RT 与 **RF**（有限正数，约在 1e-4～1e4）

（可选）**多点校正** → **演示三点（0.5/1.0/1.5）** → **拟合**：甲醇与主酯有 R²；R²<0.99 只黄字，不挡门禁。

- [ ] 峰数约 16，内标已积分
- [ ] 甲醇 RF 已写入，校正门可通过

**建议：** 此时 **另存厂方法** 为例如 `厂-已校正-验收.bjm`（含 RF + 粮谷限量 0.6）。不合格演示后用它恢复，避免误点 **加载默认浓香方法包** 清掉 RF。

### A2. 样品合格

1. 打开 `sample-nongxiang.ocb` → **推荐积分**（约 16 峰）
2. **样品与定量** 页填写：

   | 字段 | 值 |
   |------|----|
   | 样品编号 | LD-BJ-001 |
   | 酒名 | 模拟浓香（演示） |
   | 批号 | 演示批 |
   | 香型 | 浓香 |
   | 酒精度 %vol | **52** |
   | 检测人 | 演示 |
   | 甲醇限量原料 | **粮谷酿造** |

3. **定量并写回峰表**
4. GB 2757 面板预期（积分边界可使含量略偏）：

   | 项 | 预期 |
   |----|------|
   | 测得甲醇 | 约 **0.180 g/L** |
   | 折算 100%vol | 约 **0.3462 g/L**（× 100 / 52） |
   | 粮谷限量 | **0.6 g/L**（100%vol，来自方法，非 Java 写死） |
   | 判定 | **合格** |

5. **预览/打印报告**：样品信息、方法摘要、谱图缩略、定量结果、GB 2757、操作者与时间；免责 **不声明执行 GB 5009.266**

- [ ] 甲醇约 0.180 g/L，判定 **合格**
- [ ] 报告字段齐全，含合格与折算说明

### A3. 样品不合格（仅演示 · 临时压低粮谷限量）

**不要**把本步报告交给质检当批次结论。短步骤副本：`demo/仅演示-不合格限量.txt`。

原理：同一张合格演示谱图，测得甲醇仍约 0.180 g/L @ 52%vol → 折算约 0.3462 g/L。把 **组分方法** 页 **粮谷甲醇限量 g/L（100%vol）** 从 **0.6** 临时改成 **0.30**（0.3462 > 0.30），判定应变为 **不合格**。出厂默认仍是 0.6；本步只改当前窗口，验收结束必须改回。

1. 样品信息改为可识别的演示编号（避免和 A2 合格报告搞混）：

   | 字段 | 值 |
   |------|----|
   | 样品编号 | LD-BJ-FAIL-DEMO |
   | 酒名 | 仅演示不合格（临时限量） |
   | 批号 | **仅演示 · 勿入库** |
   | 酒精度 / 原料 | 仍为 **52** / **粮谷酿造**（不要靠改酒精度造假结论） |

2. **组分方法** 页：粮谷甲醇限量改为 **0.30**（不要改「其他原料」限量，本步用的是粮谷）
3. 回到样品页 → **定量并写回峰表**
4. 预期：测得甲醇仍约 0.180 g/L；折算仍约 0.3462；**限量 0.30**；判定 **不合格**；报告 GB 2757 为不合格
5. **立刻恢复**（关闭白酒分析窗会把当前限量写入本机偏好）：

   - **首选：** **加载厂方法** → 选 A1 保存的 `厂-已校正-验收.bjm`（RF + 0.6 一起回来）
   - **或：** 粮谷限量改回 **0.6** → **保存方法**
   - **不要**用 **加载默认浓香方法包** 当恢复手段（会清除 RF）

6. 再定量一次（样品编号可改回 LD-BJ-001）：须重新 **合格**，限量来源再次显示 0.6

备用（仍标仅演示，不如改限量干净）：酒精度临时填 **25**（0.180×100/25=0.72>0.6）再定量，出不合格后改回 **52**。不要把改酒精度当成真机不合格。

- [ ] 临时限量 0.30 后判定 **不合格**（报告可作废，批号含「仅演示」）
- [ ] 已恢复粮谷限量 **0.6**，再定量为 **合格**

### A4. 门禁负向（各至少一条）

**校正门（推荐本机做完）：** 须已按 A1 **另存** `厂-已校正-验收.bjm`。

1. **加载厂方法** → 选 `demo/nongxiang-fid-default.bjm`（出厂包，**无 RF**）
2. 样品谱图仍打开时点 **定量并写回峰表** → 中英提示先混标校正，**不写含量、不做 GB 2757**。无「强制继续」
3. **加载厂方法** → 选回 `厂-已校正-验收.bjm`，组分方法页甲醇 RF 应回来

不要用 **加载默认浓香方法包** 当第 3 步的恢复（会清 RF）。若没有 A1 备份：本条可改走 `demo/回归检查清单.txt` 第 5 项，备注写明。

**许可门：** 安装时已验证过即可勾选。未授权时仍可打开 `.ocb`、推荐积分、混标校正；**定量 / 报告** 被拦。不要在已导入厂许可的验收机上删许可文件，除非有备份可立刻导回。

- [ ] 校正门负向：无 RF 时不能定量，随后已用已校正 `*.bjm` 恢复
- [ ] 许可门负向：未授权不能定量/出报告（本机或安装时已验证）

脚本 A 结束前：

- [ ] 粮谷限量已回到 **0.6**（组分方法页可见）

## 6. 脚本 B — 真机验收

热机、点火、进样仍手动。采集走 **气相色谱控制台** 主界面（手册第 4～5 节）。每针：进样 → **开始分析 → 启动** → 停止/ACQ_DONE → **白酒分析** → 推荐积分 → 校正或定量。

方法、内标加标与厂约定一致（默认：样品 1.00 mL + 内标 0.10 mL，贮备液 17.6 g/L）。**酒精度、原料按该针真实情况填写**，不要为了合格/不合格去改数字。

### B0. 开机

- [ ] 载气 / 氢气 / 空气已开；**设置 / 通讯** 已连接（主界面 **已连接**）
- [ ] 主界面 **FID 就绪**（已连接 + 检测器在线 + 火焰已着）后再开始分析
- [ ] 未使用 FID 开发旁路

### B1. 真混标一针

厂方 15 组分 + 乙酸正丁酯混标，柱与方法包一致（XP-白酒 C2）。

1. 进样混标 → 采集落盘 → 打开刚保存的 `.ocb`（或点保存对话框 **白酒分析**）
2. **推荐积分**；峰数应接近库内 16（实机允许缺峰，须在备注写明并补窗口/指定峰）
3. **用当前谱图做校正**（或真机三档 **多点校正** ≥3 点后 **拟合**）
4. 组分方法页甲醇 **RF** 有效

- [ ] 真混标已进样、已积分、甲醇 RF 已写入
- [ ] 实测本机 RT 与窗口可用（与演示 +0.055 min 不同属正常，改本机 RT 后 **应用选中行**）

**建议：** **另存厂方法** `厂-真机已校正-验收.bjm`。

### B2. 真样品合格一针

取预期合格的粮谷（或实际原料）生产样 / 留样。加标与 B1 相同。

1. 进样 → 采集 → **推荐积分** → 填 **真实** 样品编号、酒名、批号、酒精度、原料、检测人
2. **定量并写回峰表**
3. 预期：折算甲醇 **≤** 该方法对该原料的限量（粮谷 0.6 / 其他 2.0，100%vol）→ **合格**
4. **预览/打印报告**，可打印或另存 PDF 附卷

若该针意外不合格：不要改酒精度或限量把报告改成合格。记入备注，另取合格样重跑 B2，或结论记不通过。

- [ ] 真样品合格针：判定 **合格**，报告留存
- [ ] 酒精度 / 原料与该酒一致（未为演示而改）

### B3. 真样品不合格一针

必须是 **甲醇折算超过 GB 2757 对应原料限量** 的真实液体，见 [§7](#7-真机不合格样品怎么准备)。禁止：把合格样改酒精度、改限量、或改原料类型来「做出」不合格——那是脚本 A 的仅演示，不能当 B3。

1. 进样不合格演示样（标签含「勿入库」）→ 采集 → 推荐积分
2. 样品编号单独一段（例如 `LD-BJ-FAIL-001`），批号写 **不合格验收样**
3. 酒精度 / 原料仍填 **真实值**
4. **定量并写回峰表** → 判定 **不合格**；折算说明里折算值 **大于** 限量
5. 报告可附卷，封面或备注标明验收用超标样，**不是**放行批次
6. 残液按实验室甲醇废液处理，不得灌装入库

- [ ] 真样品不合格针：判定 **不合格**，折算超过限量
- [ ] 未改限量、未改酒精度造假；样液已按危化/废液处理

脚本 B 结束前：

- [ ] 厂方法粮谷/其他限量仍为出厂或厂方批准值（未被 B 步改掉）

## 7. 真机不合格样品怎么准备

目标：在 **真实酒精度、真实原料类型、出厂限量不动** 的前提下，让折算甲醇超过限量。

折算：`测得甲醇(g/L) × 100 / 酒精度(%vol)`，与限量（100%vol）比较。**大于** 限量 → 不合格（等于为合格）。

粮谷限量 0.6 g/L @100%vol 时，现场甲醇（g/L）须 **大于** `0.6 × 酒精度 / 100`：

| 酒精度 %vol | 粮谷不合格阈值（测得甲醇 g/L） | 建议加标后目标（留余量） |
|-------------|-------------------------------|--------------------------|
| 52 | > 0.312 | 约 **0.50** g/L |
| 42 | > 0.252 | 约 **0.40** g/L |
| 38 | > 0.228 | 约 **0.40** g/L |

**推荐做法：** 取已定量合格的粮谷酒作底液，用分析纯甲醇 **少量加标** 到上表目标，混匀，贴「不合格验收样 / 有毒 / 勿入库 / 勿饮用」。先按方法加内标再进样一针。

**不要：**

- 改组分方法里的 0.6 / 2.0 来让合格样变不合格（那是脚本 A）
- 把原料改成「其他」却仍按粮谷限理解（其他限量是 2.0，更难超）
- 把软件演示 `.ocb` 改字节冒充真机谱图
- 验收结束后把加标酒当产品或合格对照

甲醇有毒，加标在通风橱、PPE、最小体积；残液按实验室规定处置。

若厂里已有真实超标留样，可直接作 B3，仍须标签与废液纪律。

## 10. 计算备忘

```
折算 100%vol 甲醇 (g/L) = 测得甲醇 (g/L) × 100 / 酒精度 (%vol)
合格：折算值 ≤ 方法中该原料限量
不合格：折算值 > 方法中该原料限量
```

演示合格样：0.180 × 100 / 52 ≈ **0.3462**，粮谷 0.6 → 合格。  
仅演示不合格：同一 0.3462，临时限量 **0.30** → 不合格。  
真机粮谷 52%vol：测得甲醇须 **大于 0.312 g/L** 才不合格。
