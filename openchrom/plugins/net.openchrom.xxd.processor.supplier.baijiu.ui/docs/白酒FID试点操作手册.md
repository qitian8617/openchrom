# 白酒 FID 试点操作手册

厂里操作员用这一份：**开箱 → 安装/许可 → 开机采集 → 白酒分析校正定量 → 报告 → 常见故障**。

不必阅读工程 PR 历史。演示点击清单（A–K）仍在 `demo/操作步骤.txt`；现场验收（真混标 / 合格 / 不合格）见 [白酒FID试点演示与验收脚本.md](白酒FID试点演示与验收脚本.md)（节 **M**）。本文把日常路径收在一起。工程师深读见文末 [技术文档索引](#技术文档索引)。

**目标操作员界面**是专用壳 **白酒 FID 工作站**（方案 B Phase 3：启动即厂工作台 = 顶栏厂工具条 + **左**工作流页签「进样序列 / 白酒分析」+ **右**固定「谱图/采集」；反控可用工具条 **反控** 显示/隐藏、停在选项卡左侧）。社区版 OpenChrom **现阶段仍支持**（帮助 → 安装新软件）。架构：[白酒FID专用壳架构.md](白酒FID专用壳架构.md)。

英文入口（仅指针，不是第二本手册）：[GCWS-OPERATOR-MANUAL.md](GCWS-OPERATOR-MANUAL.md)。

## 1. 产品范围与不做事项

本手册对应试点功能 **Baijiu FID Pilot（白酒FID试点）**，安装后得到：

| 能力 | 界面入口 |
|------|----------|
| 白酒分析、定量、报告 | **插件 → 白酒工作台**（或 **窗口 → 视图 → 白酒工作台**）。专用壳：**白酒 → 定量/白酒分析**（样品→校正→定量→报告页） |
| 气相色谱控制台（反控主界面） | 气/火/信号、**开始分析**、采集落盘。专用壳：工具条 **反控** 显示/隐藏左侧 sash（默认可见）；**白酒 → 气相色谱控制台** 也会打开。社区版仍是对话框 |

白酒分析插件 `baijiu.ui` 与反控 `temperature.ui` 均为 **JavaSE-21**（**不要**把这两个插件的 BREE 升到 JavaSE-25）。专用壳 / 社区 OpenChrom 1.6.32 **启动**时 ChemClipse 内核需要 **Java 25** 运行时；Java 25 可以跑 21 的插件。

**本试点做：**

- 打开 FID 单通道色谱图（CSD / `.ocb`），推荐积分，混标校正，样品定量
- 甲醇 **GB 2757** 判定（粮谷 / 其他原料限量来自厂方法，不写死在判定逻辑里）
- 预览 HTML 报告、系统打印/另存 PDF、导出 CSV
- 简单进样序列编排、平行样均值与相对偏差、批处理结果表
- 离线 `*.bjlic` 许可；未授权仍可开谱图与积分

**本试点不做（不要对外承诺）：**

- 不声明执行 **GB 5009.266**
- 无 21 CFR Part 11 审计、无 LIMS 推送
- 不控制自动进样器；热机、点火、进样仍手动
- 白酒分析窗里的气路文字是提醒，**软件不控仪器气路**（「气路由人工作，软件不控制仪器。」）
- 无加密狗、无在线激活服务器
- 不重写峰检测 / 不 Electron / 无 Part 11。社区产品仍保留。新厂机优先跑 **白酒 FID 工作站** 专用壳；已有社区版仍可用 **帮助 → 安装新软件**

## 2. 开箱与安装

### 2.1 两种安装车（专用壳是目标）

| 车 | 何时用 | 厂里看到什么 |
|----|--------|----------------|
| **白酒 FID 工作站（专用壳，目标操作员 UI）** | 新机器、新试点桌面 | 窗口标题 **白酒 FID 工作站**，启动即 **厂工作台**：**左**选项卡 **进样序列 / 白酒分析**，**右**固定 **谱图/采集**；反控 sash 停在选项卡左侧，可用工具条 **反控** 开关（默认可见）。顶栏 **文件 / 白酒 / 视图 / 帮助**（无处理器/插件）。工具条：**打开谱图**、**反控**、开始分析、推荐积分、定量/白酒分析、报告。窗口布局会记住；要恢复默认：白酒 → 重置窗口布局，然后重启 |
| **社区版 OpenChrom + 安装新软件** | 厂机上已经在跑社区版 | 帮助 → 关于仍写 OpenChrom；再装 Baijiu FID Pilot。**现阶段仍支持** |

专用壳 **不是** 再实现一套积分/定量，内核仍是 OpenChrom / ChemClipse。架构见 [白酒FID专用壳架构.md](白酒FID专用壳架构.md)。工程师 Run / Export：[产品 README](../../../products/net.openchrom.rcp.compilation.baijiu.product/README.txt) 与 [GCWS-INSTALL.md](GCWS-INSTALL.md)。

### 2.2 安装（厂里已有社区版）

工程师交给厂里的通常是一个文件夹（也可打成 zip / U 盘），例如 `D:\baijiu-fid-pilot-site`。里面是 p2 元数据。分类名：**白酒 FID 试点 / Baijiu FID Pilot**。勾选安装 **Baijiu FID Pilot（白酒FID试点）** 即可同时得到白酒分析 + 气相反控。

1. **帮助 → 安装新软件… → 添加… → 本地…**
2. 选 U 盘/文件夹里的站点目录（或解压后的 `repository`）
3. 分类 **白酒 FID 试点** → 勾选 **Baijiu FID Pilot** → 下一步 → 接受许可 → 按提示重启
4. 核对版本：**帮助 → 关于 OpenChrom → Installation Details → Installed Software**  
   应看到 **Baijiu FID Pilot（白酒FID试点）** **1.6.32.***（qualifier 会变）  
   Plug-ins 页应有 `net.openchrom.xxd.processor.supplier.baijiu.ui`
5. **插件 → 白酒工作台**（或 **插件 → 白酒工作台 → 切换白酒工作台**）应能打开右侧日常按钮

升级：用更新后的同一类文件夹再装一次，重启。许可文件会留在本机，一般不用重导。

若 **安装新软件** 被策略拦住，工程师可用 dropins 应急（见 [GCWS-INSTALL.md](GCWS-INSTALL.md)）。厂里优先走 p2，方便以后升级替换。

### 2.3 工程师如何导出

**A. 专用壳产品（优先给新厂机）**

已能编译 `baijiu.ui` 的 Eclipse。打开  
`openchrom/products/net.openchrom.rcp.compilation.baijiu.product/openchrom.compilation.baijiu.product`  
→ **Run As → Eclipse Application** 本机看窗口标题；或 **Export Eclipse Product** 到例如 `D:\baijiu-fid-workstation`（内含 JustJ **Java 25**，不要只用 JRE 21 去导）。  
`baijiu.ui` 工程 Execution Environment 必须仍是 **JavaSE-21**。

**B. 社区版插件站点（已有 OpenChrom 时）**

**文件 → 导出 → Plug-in Development → Deployable Features**  
勾选 **Baijiu FID Pilot (白酒FID试点)** → 目录例如 `D:\baijiu-fid-pilot-site` → 生成仓库元数据。

社区 `.product` **不要删、不要改成白酒壳**。细节见 [GCWS-INSTALL.md](GCWS-INSTALL.md)。

## 3. 导入许可

定量、报告、简单批量、批处理结果、平行样含量需要有效离线许可。开谱图、推荐积分、混标校正、改方法 **不需要** 许可，也不会损坏 OpenChrom 核心。

### 3.1 演示许可

插件目录：`demo/sample-pilot.bjlic`

| 字段 | 演示值 |
|------|--------|
| site | 示例酒厂 |
| customer | Pilot Demo |
| 有效期 | 至 2027-12-31 |
| product | `baijiu-fid-pilot` |

正式厂许可由供应商签发，不要把演示文件当生产授权。

### 3.2 导入步骤

任选其一：

- **插件 → 白酒工作台 → 许可…**（工作台按钮文案：**许可 / 版本…**；白酒分析窗同样有此按钮）
- **窗口 → 首选项 → 白酒 FID 许可**

然后：

1. **导入 *.bjlic…** → 选 `sample-pilot.bjlic`（或厂方文件）
2. 状态须为 **许可：有效**，并显示厂名、客户、截止日期、插件版本
3. 也可把文件放到 `%USERPROFILE%\OpenChrom\licenses\baijiu-fid.bjlic`（即 `~/OpenChrom/licenses/baijiu-fid.bjlic`）

无需联网。也可粘贴一行密钥 `BAIJIU1|site|customer|expires|key` 后点 **应用粘贴的密钥**。

### 3.3 未授权时会看到什么

| 仍可用 | 被拦住（中英对照提示） |
|--------|------------------------|
| 打开 `.ocb` / CSD、推荐积分、混标校正、组分方法编辑 | **定量并写回峰表**、**预览/打印报告**、简单批量、批处理结果含量、平行样含量 |

提示大意：「白酒 FID 试点尚未授权。仍可打开色谱图、推荐积分与混标校正；定量、报告、简单批量与批处理结果已停用。」过期 / 密钥无效 / 产品不匹配时文案不同，见 [常见故障](#12-常见故障)。

开发旁路 `-Dnet.openchrom.baijiu.skipLicenseGate=true` **禁止**在生产或试点现场使用。

## 4. 日常开机与气 / 火 / 信号

实机路径走 **气相色谱控制台** 主界面（反控），不是白酒分析窗里的气路文字。

专用壳（白酒 FID 工作站）：启动后 **厂工作台** 主区默认是 **进样序列** 页签；左侧气相色谱控制台（气/火/信号、FID 就绪、当前针）可用工具条 **反控** 显示或隐藏。工具条 **打开谱图** 与 **文件 → 打开 CSD 文件** 同一路径。工具条 **开始分析** 与主界面「启动」同一道门，成功后切到 **谱图 / 采集** 大图。**白酒 → 气相色谱控制台** 会把反控 sash 显示并提到前面。

社区版仍从 **插件** 菜单打开浮动控制台窗口（对话框），行为与以前相同。日常专用壳顶栏 **没有**「处理器 / 插件」。工程师若要看 ChemClipse 峰检测退路，须加启动参数 `-Dnet.openchrom.baijiu.showResearchMenus=true`（手册以外不要开）。

1. 打开载气、氢气、空气（目视调节器）。载气 **没有** 软件传感器，主界面只提醒，不显示假流量。
2. **设置 / 通讯** 连接色谱仪（F407），等待握手成功（主界面连接显示 **已连接**）。
3. 按日常升温：进样口 / 检测器 / 柱箱。
4. 到 **检测器** 页点火。主界面 FID 条显示 H₂ / 空气 MPa、火焰、FID 信号（pA）。
5. 等到主界面标题为 **FID 就绪**（已连接、检测器在线、火焰已着）再点 **开始分析**。

主界面 **开始分析 → 启动** 默认门禁：必须 **已连接 + FID 在线 + 火焰已着**。**停止** 随时可用。

| 主界面状态 | 含义 | 操作员怎么做 |
|------------|------|----------------|
| FID 就绪 | 可以开始分析 | 进样后点 **开始分析 → 启动** |
| FID 准备中 | 正在读状态或正在点火 | 等待 |
| FID 未就绪 | 未连接 / 板离线 / 未着火 / 点火失败 | 按提示检查网线、485、气、阀后再点火 |
| 未连接 | 通讯未握手 | **设置 / 通讯** 先连上；未连接时开始分析一律被拦 |

Android 面板与电脑可同时连 F407，但 **PC 在线时面板只读 + 急停**；采集 **开始分析 / 停止** 只在工作站上做。不要试图让面板与电脑互相同步。

开发旁路 `-Dnet.openchrom.gcws.skipFidReadinessGate=true` 会在 FID 条显示醒目的「开发旁路 / DEBUG」横幅，火焰未着也可开始分析。**仅研发本机验证，禁止试点现场。** 未连接设备时即使用旁路也不能开始分析。

反控细节：[GCWS-DUAL-CONTROL.md](../../net.openchrom.xxd.control.supplier.temperature.ui/docs/GCWS-DUAL-CONTROL.md)

## 5. 采集落盘与进入白酒工作台

热机、点火、进样仍手动。软件负责采集、落盘、交白酒工作台。

1. （可选）厂工作台主区 **进样序列** 页签 → **填入典型队列**，反控主界面会显示 **当前针**。
2. 按当前行列入手动进样。
3. 主界面 **开始分析 → 启动**（或顶栏 **开始分析**）。工作站切到 **谱图 / 采集** 页签画实时谱图后，序列该行变为 **运行中**。
4. 跑完点 **停止**，或等仪器 `ACQ_DONE`。
5. 成功：对话框给出文件路径，默认按钮 **白酒分析**。文件写在 `~/OpenChrom/Acquisitions/`，文件名 `GC-FID_yyyyMMdd_HHmmss.ocb`（写不出 `.ocb` 时同名 `*.xy` 兜底）。当前序列行变为 **已完成** 并带上谱图路径，指针前进。
6. 点 **白酒分析**（或回车）：切换到 **白酒工作台** 并打开刚保存的谱图。然后：**推荐积分 → 白酒分析 → 校正/定量 → GB 2757 → 报告**。
7. 若点 **关闭**：谱图仍已保存。以后可用 **文件 → 打开 CSD 文件** 或工作台 **打开色谱图** 再打开。
8. 失败：中英警告。不要关掉还在的实时谱图。该序列行标 **失败**，可在进样序列里 **重试** 或 **跳过**。

可勾选对话框 **保存后自动打开白酒工作台**（默认关）。

离线、没有仪器时：跳过本节，直接打开演示 `.ocb`，后面定量路径相同。白酒分析读的是 **当前已打开的 FID 谱图**，不管来自采集还是演示目录。

采集细节：[GCWS-ACQUISITION-SAVE.md](../../net.openchrom.xxd.control.supplier.temperature.ui/docs/GCWS-ACQUISITION-SAVE.md)

## 6. 浓香方法包 / 组分库

打开 **白酒 → 定量/白酒分析**（专用壳是分析页：样品 → 校正 → 定量 → 报告）。社区版仍是 **插件 → 白酒工作台 → 白酒分析** 对话框。默认已加载 **浓香 FID 默认方法**：

| 项 | 约定 |
|----|------|
| 方法名 | 浓香 FID 默认方法 |
| 柱 | XP-白酒 C2，30 m × 0.32 mm × 1.00 μm |
| 内标 | 乙酸正丁酯，贮备液 17.6 g/L |
| 加标 | 样品 1.00 mL + 内标 0.10 mL → 进样内标浓度 **1.6000 g/L** |
| 库 | 15 个待测 + 内标（演示谱图约 16 个峰） |
| 本机 RT | 厂商参考 RT + 0.055 min，默认窗口 ±0.15 min |
| 采样 | 20 Hz，约 0–19 min |

出厂方法包 **不含 RF、不含多点校正点**。加载后必须再做混标校正才能定量。

### 6.1 厂方法文件

| 按钮 | 作用 |
|------|------|
| **另存厂方法** | 当前柱/内标/15 混标/本机 RT/窗宽/是否定量/是否甲醇判定/**已写入的 RF 与多点点** → UTF-8 `*.bjm` |
| **加载厂方法** | 用一个 `*.bjm` 覆盖当前方法；文件里若已有有效甲醇 RF，定量门禁可通过 |
| **加载默认浓香方法包** | 恢复 XP-C2 + 乙酸正丁酯 + 15 混标及四项标志。**会清除 RF 与多点校正点**，必须重新校正 |
| **保存方法** | 只写入本机偏好，不是文件 |

演示文件（与插件内置包一致，无 RF）：

- `demo/nongxiang-fid-default.bjm`
- `demo/浓香FID默认方法.bjm`

### 6.2 组分方法页

页签名 **组分方法**。选中一行，改 **本机RT**、**窗口**，勾选 **是否定量**、**是否甲醇判定**，点 **应用选中行**。

- 内标乙酸正丁酯 **固定不定定量**
- **是否甲醇判定** 最多勾一个（默认甲醇）
- 不定定量：峰匹配仍显示该组分，定量表不写含量
- 取消甲醇判定（或把甲醇改为不定定量）：定量仍走混标门禁，但 **不做 GB 2757**（不会把缺甲醇当成未检出/合格）

深读：[GCWS-METHOD-PACKAGE.md](GCWS-METHOD-PACKAGE.md)、[GCWS-COMPOUND-LIBRARY.md](GCWS-COMPOUND-LIBRARY.md)

## 7. 混标校正（单点 + 多点）与门禁

**没有有效混标校正，样品不能定量、不能出报告。** 没有「强制继续」。向导、简单批量、批处理结果、平行样含量走同一扇门。

### 7.1 有效校正是什么

方法里甲醇（GB 2757 目标，默认可改）的 **响应因子 RF** 必须是有限正数，范围 **1e-4～1e4**。单点 **用当前谱图做校正** 或多点 **拟合** 都会写入这张 RF 表。

其他组分缺 RF 时，结果表该行显示未校正，**单独不挡** GB 2757；甲醇 RF 无效则整次定量被拦。

### 7.2 单点（日常默认）

1. 打开混标谱图（演示：`mix-15plus-istd.ocb` / `白酒混标_15组分加内标.ocb`）
2. **推荐积分**（一阶导数阈值 MEDIUM + 梯形积分；专用壳也可仍走精简后的 **色谱 → 峰检测 → 一阶导数** 再 **色谱 → 峰积分 → 峰梯形积分器**。日常不要用处理器/研究色谱子菜单）
3. 左侧峰/扫描约 **16** 个峰，面积不为 0；**峰匹配** 页应看到内标 **乙酸正丁酯**（本机约 10.382 min）
4. 确认内标体积与贮备液为默认，点 **用当前谱图做校正**
5. **组分方法** 页应出现本机 RT 和 RF

### 7.3 多点（白酒分析 → 多点校正；对应演示节 I）

拟合对象：甲醇 + 乙酸乙酯 / 乳酸乙酯 / 己酸乙酯。其余组分仍用单点 RF。

**离线演示（不必准备三档实机谱图）：**

1. 同一张演示混标，推荐积分后打开 **多点校正**
2. 点 **演示三点（0.5/1.0/1.5）**  
   或勾选 **离线演示：按倍数缩放待测峰面积（内标不变）**，倍数分别填 0.5 / 1.0 / 1.5，三次 **从当前谱图添加校正点**，再 **拟合**
3. 表中甲醇与至少两种主酯应有斜率、截距、R²（演示线近乎 R² = 1）
4. **拟合** 把有效 RF 写入方法；样品定量与门禁仍走原 RF 表

**真机三档混标：** 取消勾选缩放，每档打开对应谱图，填 **本针混标倍数**，**从当前谱图添加校正点**，≥3 点后 **拟合**。

**R² < 0.99 只黄字提示，不阻定量，不是法规限。**

同谱图、不缩放面积、却改倍数：y 几乎不变而 x 在变 → 斜率≈0、R² 差。离线请用演示三点或勾选缩放。

深读：[GCWS-CALIBRATION.md](GCWS-CALIBRATION.md)、[GCWS-MULTIPOINT.md](GCWS-MULTIPOINT.md)

## 8. 样品定量与 GB 2757

1. 打开样品谱图（演示：`sample-nongxiang.ocb` / `白酒样品_浓香模拟.ocb`）→ **推荐积分**
2. **白酒分析** → **样品与定量** 页填写（演示建议值）：

   | 字段 | 演示值 |
   |------|--------|
   | 样品编号 | LD-BJ-001 |
   | 酒名 | 模拟浓香（演示） |
   | 批号 | 演示批 |
   | 香型 | 浓香 |
   | 酒精度 %vol | 52 |
   | 检测人 | 演示 |
   | 甲醇限量原料 | 粮谷酿造 |

   原料类型 **只用于 GB 2757 甲醇限量，与香型无关**。酒精度为手工录入。

3. 点 **定量并写回峰表**
4. 成功后，**GB 2757 甲醇判定** 面板显示：判定（合格 / 不合格 / 无法判定）、测得甲醇、折算说明、限量来源

演示样品（积分边界可使结果略偏）：

| 项目 | 约值 |
|------|------|
| 测得甲醇 | 0.180 g/L |
| 折算 100%vol | 0.3462 g/L（测得 × 100 / 52） |
| 粮谷限量 | 0.6 g/L（100%vol，来自厂方法/偏好） |
| 判定 | 合格 |

**折算公式：** 测得甲醇(g/L) × 100 / 酒精度(%vol)

未校正时弹出中英提示，**不写含量、不做 GB 2757**，避免把未校正甲醇当成「未检出/合格」。

新操作员可用 **三步向导**：① 方法/样品 ② 谱图处理（推荐积分） ③ 结果与报告。向导完成前同样要有混标校正与有效许可。

## 10. 进样序列 / 平行样 / 批处理结果

这三块是日常批量的简要路径，不是第二套 LIMS。均要求 **已混标校正**；含量类操作还要求 **许可有效**。

### 10.1 进样序列

专用壳：厂工作台主区第一页签 **进样序列**。社区版：**插件 → 白酒工作台 → 进样序列**。

1. **填入典型队列**，样品数填当天针数 → 空白 → 混标 → QC → 样品×N
2. 可改编号/名称，**上移 / 下移**，**保存序列… / 打开序列…**（默认 `~/OpenChrom/Sequences/`）
3. 选中样品 → **添加平行样** 插入第二针（同编号，类型仍为样品，表中 **平行针 A/B**）
4. 气相色谱控制台主界面显示 **当前进样**。按当前行进样后点 **开始分析**；保存成功后该行完成并带谱图路径，自动前进
5. 反控底栏 **没有「序列」页**。不控制自动进样器

空序列 **不阻挡** 开始分析。

### 10.2 平行样

相对偏差 % = |针A − 针B| / 均值 × 100%；均值 = (针A + 针B) / 2。甲醇标为 **甲醇（重点）**。不做 Shewhart / 多点 RSD。

- 工作台 **平行样**：针 A / 针 B 各选一个 `.ocb`（演示可两次选 `sample-nongxiang.ocb`）→ **计算均值与偏差**
- 进样序列：两针都进样保存后 **平行样结果…**
- 简单批量：相同样品编号的两行会配对

### 10.3 批处理结果 vs 简单批量

| 入口 | 干什么 |
|------|--------|
| **批处理结果** / 进样序列 **生成结果表** | 按当前进样序列 **每一针一行**。待进样 / 已跳过 / 失败仍列出原因，不会悄悄丢掉 |
| **简单批量** | 多选已保存 `.ocb`，同一方法，样品×组分表。**不读序列** |

离线无硬件：打开 `demo/sequence-batch-results.json`，先把其中 `chromatogramPath` 改成本机演示 `.ocb`，再 **打开序列 JSON…** → **生成结果表**。可 **导出汇总表**（UTF-8 带 BOM 的 CSV）。

深读：[GCWS-SEQUENCE.md](../../net.openchrom.xxd.control.supplier.temperature.ui/docs/GCWS-SEQUENCE.md)、[GCWS-PARALLEL.md](GCWS-PARALLEL.md)、[GCWS-BATCH-RESULTS.md](GCWS-BATCH-RESULTS.md)

## 12. 常见故障

### 装不上 feature

- 确认选的是 **本地文件夹**（p2 站点），不是随便一个 zip 里的源码树。
- 分类应出现 **白酒 FID 试点**；勾选包装功能 **Baijiu FID Pilot**，不要只装白酒分析却漏掉反控（包装功能已包含 `temperature.ui`）。
- 安装后必须 **重启**。再到 **帮助 → 关于 → Installation Details** 看 1.6.32.*。
- 若向导报依赖/许可错误：社区版 OpenChrom 过旧或 Java 不是 21。本插件 **BREE = JavaSE-21**，不要用 Java 25 去跑这套试点。
- 被策略禁止 p2 时，让工程师按 [GCWS-INSTALL.md](GCWS-INSTALL.md) 做 dropins，重启加一次 `-clean`。优先仍用安装新软件，便于升级。

### 许可无效 / 尚未授权

| 状态行 | 处理 |
|--------|------|
| 未授权 / unlicensed | **导入 *.bjlic**；或把文件放到 `OpenChrom\licenses\baijiu-fid.bjlic` |
| 已过期 / expired | 向供应商要新文件；谱图与积分仍可用 |
| 密钥无效 / invalid key | 不要手改 `key=`；重新导入厂方原件 |
| 产品不匹配 | 文件须 `product=baijiu-fid-pilot` |
| 格式无效 | 需要 site、customer、key；expires 为 `yyyy-MM-dd`。可先导入 `demo/sample-pilot.bjlic` 验证软件 |

未授权时定量/报告弹出中英框，**不会**把 OpenChrom 核心弄坏。导入成功后状态须含 **许可：有效**。

### 未校正被拦

提示：「无法定量：方法尚未混标校正（甲醇 RF 未校正）。请先打开混标谱图，点「推荐积分」再点「用当前谱图做校正」…」

- 刚点过 **加载默认浓香方法包** 会清 RF，必须重新校正。出厂 `*.bjm` 同样没有 RF。
- 甲醇 RF 为 NaN / 0 / 超范围（须在 1e-4～1e4）同样被拦。
- 没有「强制继续」。先做第 7 节。
- 许可门与校正门是两扇门：两扇都要通过才能定量/出报告。

### 峰数不对

演示混标/样品在 2–17 min 应约 **16** 峰，面积不为 0。

- 先点 **推荐积分**，不要只打开谱图就校正。
- 积分后仍远少于 16：确认打开的是演示 `.ocb` 而不是空文件/错文件；实机则检查是否进样、火焰、衰减。
- 峰匹配页内标不是乙酸正丁酯或不在约 10.382 min：本机 RT 偏移可能不是 +0.055 min。到 **组分方法** 改本机 RT / 窗口后 **应用选中行**，再积分或手动 **指定选中未匹配峰**。
- 研究类检测/积分退路仍在精简后的 **色谱** 菜单（峰检测 / 峰积分）；工作台 **推荐积分** 是日常入口。专用壳会藏处理器等研究项。

### 谱图峰名 / 坐标轴看不清

专用壳启动时会把 ChemClipse 色谱图 **峰标签** 从 8 磅 Verdana 调到 **微软雅黑 13 磅粗体**，坐标轴文字改近黑（`#111111`）。打开 CSD 后峰名和「时间 [min] / 强度」应能在厂屏上看清。

仍偏小：窗口 **首选项 → 常规 → 外观 → 颜色和字体 → Charts**（专用壳仍保留首选项）。改「Chromatogram Chart Target Reference Peak Label Font」和 Axis Minutes / Intensity Font、Line Color。常量在壳插件 `BaijiuChromatogramReadability`（每次启动会再写入厂默认）。社区 OpenChrom 不改这套默认。

### RF / R² 异常

- 单点后组分方法页 RF 仍为「-」：校正未成功。看状态栏；确认内标已匹配且已积分。
- 多点 R² 很差：离线时是否忘了勾选缩放或没用 **演示三点**；真机则检查三档浓度声明是否与实际进样一致。
- R² < 0.99：黄字 **仅提示**，只要甲醇有效 RF 仍可定量。不要把它说成国标限。
- 清空多点校正点 **不会** 自动清掉已写入的 RF；**加载默认浓香方法包** 才会清 RF。

### 报告打不开

- 未定量成功：先过许可门 + 校正门 + **定量并写回峰表**。
- 定量失败对话框标题为 **白酒报告**，内容与定量失败相同。
- **打印 / 另存为 PDF** 打不开系统对话框：查本机默认浏览器/打印组件；试点不另装 PDF 库。
- 谱图缩略空白：该文件没有扫描点时会写「不可用」，报告其余部分仍应在。
- Excel 打开 CSV 乱码：用 **导出 Excel(CSV)**（带 BOM），不要用无 BOM 的 **导出 CSV**。

### 窗口布局乱了（专用壳）

专用壳会记住分隔条和窗口大小。若界面挤在一起或反控不见：

1. **白酒 → 重置窗口布局**
2. 关掉工作站再打开

工程师也可在启动参数里临时加一次 `-clearPersistedState`。日常顶栏没有「窗口」菜单。社区版不受影响。

### Java / BREE

- **插件编译**：白酒分析、反控、专用壳 branding 均为 **JavaSE-21**。**不要**把 `baijiu.ui` 的 BREE 升到 JavaSE-25。
- **产品启动**：专用壳与社区 OpenChrom 1.6.32 的 ChemClipse 内核要求 **Java 25**（JustJ / `osgi.requiredJavaVersion=25`）。快捷方式指向产品自带 JRE 即可，不要为了「手册写过 21」去换 JRE 21 启动整个 RCP。
- 关于页若出现 `LaiendeAboutHandler` ClassNotFound，属已知环境噪声，可忽略；与白酒试点无关。
- CDK / inchi unresolved 同样可忽略。

### FID 未就绪 / 无法开始分析

按主界面中文提示逐条：

| 提示 | 处理 |
|------|------|
| 未连接设备 | **设置 / 通讯** 连 F407，握手成功后再开始分析 |
| 正在读取 FID 状态 | 等 |
| 读取 FID 状态失败 | 网线、端口；持续失败查 F407 通讯 |
| FID 板离线（RS485 无应答） | 检测器电源与 485 线，再到 **检测器** 页 |
| 点火未成功 / 火焰未着火 | **检测器** 页核对 H₂/空气压力与阀，重新点火 |
| 正在点火 | 等火焰判定 |

空气读数 0.000 MPa 时火焰往往点不着——先解决气路，不要开开发旁路去采集报正式数据。

### 谱图打不开

- 用 **文件 → 打开 CSD 文件**，不要找「类型」下拉框。点文件本身，等红字消失再 **完成**。
- 工作台 **打开色谱图** 失败时，提示也会让你改用上述菜单。
- 只认工作站能打开的格式：优先 `.ocb`，其次采集兜底 `*.xy`。厂商原始文件若打不开，先转成 CSD 能认的格式。
- 批处理结果「谱图文件不存在」：`chromatogramPath` 还停在 `E:/OpenChrom/baijiu-demo/...`，改成本机路径。
- 采集失败不要关实时编辑器；应急 `*.acq.tsv` 路径会写在警告框里。

### 白酒工作台切不过去

提示「无法切换视图」时：专用壳用 **白酒 → 切换厂工作台**；社区版 **窗口 → 视图** 里选 **白酒工作台**。确认已安装并重启过 Baijiu FID Pilot。

### 厂工作台页签是深灰、没有控件

冷启动后顶栏须能看到厂工具条（**打开谱图** / **反控**），**左侧**须有 **进样序列 / 白酒分析** 页签，**右侧**须有 **谱图/采集**；打开 CSD 必须出现在右侧，不能把白酒分析换边。「气相色谱控制台」「进样序列」「白酒分析」里必须能看到 FID 控件 / 序列表 / 分析页，**或者**页内白字错误说明。若整块深灰、连错误字都没有：白酒 → **重置窗口布局**，然后重启。页内若出现异常类名，把全文发给工程师（插件未加载或面板构造失败）。找不到打开谱图：用工具条 **打开谱图** 或 **文件 → 打开 CSD 文件**，不要找灰色 Eclipse New/Open 工具条。

### 定量与报告「看起来能点」但仍停用

同时检查：

1. 许可状态是否 **有效**（第 3 节）
2. 甲醇 RF 是否已写入（第 7 节）
3. 当前打开的是否为已积分的 **样品** 谱图（不要对空编辑器定量）
