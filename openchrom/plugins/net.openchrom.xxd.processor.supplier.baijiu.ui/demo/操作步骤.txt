白酒分析演示数据（模拟 FID 谱图，非实机进样）

文件位置：E:\OpenChrom\baijiu-demo\
  混标：白酒混标_15组分加内标.ocb  （或 mix-15plus-istd.ocb）
  样品：白酒样品_浓香模拟.ocb  （或 sample-nongxiang.ocb）

说明：CSD 是 FID 单通道数据类型，不是扩展名。.ocb 是本工作站固有色谱格式（与已能打开的农药残留样同格式）。这不是厂商实机原始文件，仅供软件流程演示。

方法约定（与插件默认值一致）
  内标：乙酸正丁酯。15 种混标中 0.3632 g/L（校正）；样品加标用贮备液安瓿 17.6 g/L
  加标：样品 1.00 mL + 内标 0.10 mL  → 进样内标浓度 1.6000 g/L
  本机 RT = 厂商参考 RT + 0.055 min（默认 ±0.15 min；内标本机 RT 10.582）
  柱：XP-白酒 C2，30 m × 0.32 mm × 1.00 μm
  库：14 个待测 + 内标（15 种混标含内标，无乙酸异戊酯）
  采样：20 Hz，0–19 min。随包演示谱图仍约 16 个峰（旧库，未重建）
  定稿方法包：demo/nongxiang-fid-default.bjm（浓香FID默认方法.bjm）

操作步骤

A. 打开混标并出峰
  1. 工作站主窗体（不是控制面板）：工具条「打开谱图」或 文件 → 打开 CSD 文件
     没有类型下拉框。留在「用户位置」，展开：E: → OpenChrom → baijiu-demo
     应能看到 mix-15plus-istd.ocb 与 sample-nongxiang.ocb（及中文同名文件）
     点文件本身，红字「请至少选择一个有效的选项」消失后点「完成」
  2. 确认谱图上 2–17 min 有 16 个峰
  3. 插件 → 白酒分析（默认已加载浓香 FID 方法：内标乙酸正丁酯 17.6 g/L，加标 1.00+0.10 mL，RT 窗口 ±0.15 min）
  4. 点「推荐积分」（一阶导数阈值 MEDIUM + 梯形积分，演示混标约 16 个峰）
     也可仍走：色谱 → 峰检测 → 一阶导数；色谱 → 峰积分 → 峰梯形积分器
  5. 左侧「峰/扫描」列表应约 16 个峰，且面积不为 0；「峰匹配」页可查看未匹配峰并手动指定
  6. 确认内标体积与贮备液为默认值，点「用当前谱图做校正」
     或打开「多点校正」页走 ≥3 点拟合（见 I）
  7. 到「组分方法」页，应看到本机 RT 和 RF 已写入；可改 RT / 窗口 / 是否定量 / 是否甲醇判定后点「应用选中行」，再另存为厂方法 *.bjm
     （默认文件名 nongxiang-fid-default.bjm；演示目录也有 浓香FID默认方法.bjm）

B. 打开样品并定量
  1. 同样打开样品 .ocb，点「推荐积分」（或先一阶导数峰检测，再峰梯形积分）
  2. 插件 → 白酒分析，填写：
       样品编号  LD-BJ-001
       酒名  模拟浓香（演示）
       批号  演示批
       香型  浓香
       酒精度  52
       检测人  演示
       甲醇限量原料  粮谷酿造
  3. 点「定量并写回峰表」
     必须已完成 A 步混标校正（方法里甲醇 RF 有效）。未校正或 RF 无效（NaN/非有限/超范围）时会**阻止定量**，弹出中英提示，请先走 A 步；不会写出含量或 GB 2757（避免把未校正甲醇当成「未检出/合格」）。
     校正有效时，样品与定量页应出现 GB 2757 面板：合格、测得甲醇、折算说明、限量来源
  4. 点「预览/打印报告」（须定量成功；未校正会被门闩拦住，与定量同一提示）
     报告应有：样品信息、方法摘要、谱图缩略、定量结果、GB 2757、操作者与时间
     「打印 / 另存为 PDF」走系统打印对话框；「导出 CSV」无 BOM，「导出 Excel(CSV)」带 BOM
     详见 J

C. 白酒工作台与向导（可选）
  1. 插件 → 白酒工作台 → 切换白酒工作台
  2. 新操作员：三步向导；熟练操作员：直接白酒分析
     向导/工作台定量前同样要有混标校正；未校正时向导无法完成、批量会直接提示
  3. 简单批量：多选 .ocb，同一方法，看样品×组分表
     方法未校正时不会出含量表

D. 进样序列（白酒工作台编排，反控主界面进样）
  1. 专用壳：厂工作台主区页签「进样序列」→「填入典型队列」，样品数填当天针数
     社区版：插件 → 白酒工作台 →「进样序列」→「填入典型队列」
     得到：空白 → 混标 → QC → 样品×N。可改编号/名称，上移下移，保存/打开 JSON（默认 ~/OpenChrom/Sequences/）
     选中样品点「添加平行样」插入第二针（同编号，类型仍为样品，表中显示平行针 A/B）
  2. 气相色谱控制台主界面显示「当前进样」。按当前行进样后点「开始分析」（成功后切到「谱图 / 采集」页签）；保存成功后该行完成并带谱图路径，自动前进
  3. 反控底栏没有「序列」页。不控制自动进样器。热机、点火、进样仍手动。白酒工作台「批处理结果」按本序列已完成针汇总；「简单批量」只处理任选已保存谱图
  详见插件 docs/GCWS-SEQUENCE.md

E. 平行样（同一样品 2 针，均值与简单偏差）
  1. 必须已完成 A 步混标校正。未校正时平行样不会写出含量（与定量同一门闩）
  2. 进样序列：选中样品 →「添加平行样」→ 两针都进样保存后点「平行样结果…」
  3. 或 白酒工作台 →「平行样」：针 A、针 B 各选一个 .ocb
     演示可两次选择 sample-nongxiang.ocb（离线、无需硬件）
  4. 简单批量：相同样品编号的两行会配对；演示可复制一份样品 .ocb
  5. 表中甲醇标为「甲醇（重点）」
     相对偏差 % = |针A − 针B| / 均值 × 100%；均值 = (针A + 针B) / 2
     不做 Shewhart / 多点 RSD
  详见插件 docs/GCWS-PARALLEL.md

F. 批处理结果（按进样序列汇总，非任选文件）
  1. 必须已完成 A 步混标校正。未校正时已完成样品行不会写出含量（与定量同一门闩）
  2. 真机：序列进样保存后，工作台「批处理结果」或进样序列「生成结果表」
     每一针一行：类型、编号、状态、谱图路径、甲醇等含量、样品的 GB 2757
     待进样 / 已跳过 / 失败的行仍列出原因，不会悄悄丢掉
  3. 离线（无硬件）：打开 demo/sequence-batch-results.json
     先把其中 chromatogramPath 改成本机 E:\OpenChrom\baijiu-demo\ 下的
       mix-15plus-istd.ocb 与 sample-nongxiang.ocb
     进样序列「打开序列…」该 JSON，再点「生成结果表」
     或 批处理结果 →「打开序列 JSON…」
  4. 「简单批量」仍可多选 .ocb，不读序列
  5. 可「导出汇总表」CSV。平行针备注里有甲醇均值/相对偏差，详细仍用「平行样」
  详见插件 docs/GCWS-BATCH-RESULTS.md

G. 厂方法包导入导出与恢复默认（定稿浓香包）
  1. 另存厂方法：白酒分析 →「另存厂方法」→ 选目录，保存 *.bjm（UTF-8）
     当前柱、内标、15 混标浓度、本机 RT、窗宽、是否定量/是否甲醇判定、已写入的 RF 和多点校正点都会进文件
  2. 再导入：改几个组分名或 RT 后，点「加载厂方法」选刚才的 *.bjm
     关键字段应恢复；若文件里已有有效甲醇 RF，定量门闩仍通过
  3. 恢复出厂默认：白酒分析 →「加载默认浓香方法包」（组分方法页同样有此按钮）
     确认后恢复 XP-白酒 C2 + 乙酸正丁酯 + 15 混标（本机 RT = 厂商 + 0.055 min）
     会清除 RF 与多点校正点，必须重新走 A 步或 I 步校正后再定量
  4. 也可直接「加载厂方法」打开插件 demo/nongxiang-fid-default.bjm
     （或 浓香FID默认方法.bjm）。详见插件 docs/GCWS-METHOD-PACKAGE.md

H. 组分库可编辑（RT / 窗宽 / 是否定量 / 是否甲醇判定）
  1. 白酒分析 →「组分方法」：选中一行，改本机 RT、窗口，勾选「是否定量」「是否甲醇判定」
     点「应用选中行」。内标乙酸正丁酯固定不定定量。甲醇判定最多勾选一个（默认甲醇）
  2. 「保存方法」写入偏好；「另存厂方法」写入 *.bjm（compound.*.rt / window / quantify / gb2757）
  3. 不定定量：峰匹配页仍显示该组分，定量表不写含量；简单批量/批处理结果可省略该列
  4. 取消甲醇判定（或把甲醇改为不定定量）：定量仍走混标门闩，但不做 GB 2757（不会把缺甲醇当成未检出/合格）
  5. 「加载默认浓香方法包」把上述四项恢复为目录默认。详见 docs/GCWS-COMPOUND-LIBRARY.md

I. 多点校正 + R²（甲醇 + 乙酸乙酯 / 乳酸乙酯 / 己酸乙酯）
  1. 仍用同一张演示混标 mix-15plus-istd.ocb（不必准备三档实机谱图）
     推荐积分后打开白酒分析 →「多点校正」
  2. 离线：点「演示三点（0.5/1.0/1.5）」
     会按声明浓度缩放待测峰面积（内标面积不变），写入 3 个校正点并拟合
     或：勾选「离线演示：按倍数缩放待测峰面积」，倍数分别填 0.5 / 1.0 / 1.5，三次「从当前谱图添加校正点」，再「拟合」
  3. 表中甲醇与至少两种主酯应有斜率、截距、R²（演示线近乎 R² = 1）
     R² < 0.99 只黄字提示，不阻定量、不是法规限
  4. 拟合把有效 RF 写入方法，样品定量与混标门闩仍走原 RF 表
     「用当前谱图做校正」单点路径仍可用
  5. 真机三档混标：取消勾选缩放，每档打开对应谱图、填该针倍数、添加校正点
  详见插件 docs/GCWS-MULTIPOINT.md

J. 报告定稿（定量后预览 / 打印 PDF / 导出 CSV）
  1. 必须已完成 A 步混标校正并成功定量（B.3）。未校正时「预览/打印报告」被门闩拦住，不打开报告
  2. 白酒分析 →「预览/打印报告」（工作台「预览报告」、向导完成亦可）
     HTML 须含：
       样品信息：样品编号、酒名、批号、香型、酒精度、原料、检测人、检测日期
       方法摘要：方法名、柱、内标、程序升温、加标（其余已有字段保留）
       定量结果：组分、RT、峰面积、RF、含量 g/L、超限、备注
         RF 为本次定量实际使用值；若刚走 I 步多点拟合，备注可有「多点拟合有效RF」
       GB 2757：合格 / 不合格 / 无法判定 + 折算说明
         免责：不声明执行 GB 5009.266
       谱图缩略：有扫描则 SVG；否则中英提示不可用
       操作者与时间：检测人、检测日期、报告生成时间
         检测人/日期缺省时用谱图操作者或分析时间
  3. 「打印 / 另存为 PDF」→ 系统对话框选打印机或另存为 PDF（Browser window.print，无额外 PDF 库）
  4. 「导出 CSV」UTF-8 无 BOM；「导出 Excel(CSV)」UTF-8 带 BOM，Excel 可直接打开
     列与 HTML 字段对齐（含检测人、检测日期、方法名、柱、内标、加标、超限、GB判定、免责声明）
  详见插件 docs/GCWS-REPORT.md

混标校正门闩（样品定量）
  有效校正：已用混标谱图算出 RF（单点或 ≥3 点拟合的有效 RF）；甲醇 RF 为有限正数且在 1e-4–1e4。内标须匹配且已积分。
  未校正 / RF 无效：白酒分析、向导、简单批量、批处理结果均阻止定量，提示先做「用当前谱图做校正」或「多点校正」拟合。无「强制继续」。
  详见插件 docs/GCWS-CALIBRATION.md、docs/GCWS-MULTIPOINT.md
