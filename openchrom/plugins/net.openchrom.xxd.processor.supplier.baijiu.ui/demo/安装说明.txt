白酒 FID 试点 — 安装与许可（短说明）

厂里操作员请先读 docs/白酒FID试点操作手册.md（开箱到报告与常见故障）。本文只覆盖安装/许可。

1. 工程师导出
   优先（新厂机）：打开 products/.../openchrom.compilation.baijiu.product
   → Run As Eclipse Application 或 Export Product（JustJ Java 25 启动；baijiu.ui 仍 JavaSE-21）
   已有社区版：Eclipse：文件 → 导出 → Deployable Features
   勾选「Baijiu FID Pilot (白酒FID试点)」到一个文件夹（如 D:\baijiu-fid-pilot-site）
   详见 docs/GCWS-INSTALL.md、docs/白酒FID专用壳架构.md

2. 厂里安装
   专用壳：运行导出的 baijiu-fid.exe，窗口标题「白酒 FID 工作站」。
   顶栏工具条有「打开谱图」「反控」；左侧是工作流页签（谱图/采集默认，另有推荐积分 / 白酒分析 / 进样序列等），右侧固定白酒操作（可拖宽、不 Detach）。
   气相色谱控制台是独立 OS 窗口（600×1024，不嵌在主窗口里），点「反控」可关（关窗即藏，再开仍是同一窗口）。打开 CSD 出现在左侧，白酒操作不换边。右侧按钮选中对应左侧页签。
   窗口布局会记住；要恢复：白酒 → 重置窗口布局，然后重启。
   已有 OpenChrom 社区版：帮助 → 安装新软件 → 添加 → 本地 → 上述文件夹
   选「白酒 FID 试点」→ 安装 → 重启
   帮助 → 关于 → Installation Details 应看到 1.6.32.*
   社区路径现阶段仍支持；专用壳是目标操作员 UI。 

3. 打开白酒分析
   插件 → 白酒工作台（或 窗口 → 视角 → 白酒工作台）
   反控主界面需要同时装上 temperature.ui（试点功能已包含）

4. 许可
   白酒工作台 → 许可 / 版本… → 导入 demo/sample-pilot.bjlic
   未授权仍可打开谱图和推荐积分；定量与报告会中英提示并停用。
   不损坏 OpenChrom 核心。无需联网。

5. 演示方法包
   demo/nongxiang-fid-default.bjm（浓香FID默认方法.bjm）
   然后按 操作步骤.txt A–J（多点=I，报告=J，安装/许可=K；厂里手册=L；现场验收=M）
