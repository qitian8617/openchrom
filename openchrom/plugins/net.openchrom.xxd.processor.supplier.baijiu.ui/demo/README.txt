白酒分析演示数据（模拟 FID 谱图，非实机进样）

文件位置：E:\OpenChrom\baijiu-demo\
  混标：白酒混标_15组分加内标.ocb  （或 mix-15plus-istd.ocb）
  样品：白酒样品_浓香模拟.ocb  （或 sample-nongxiang.ocb）

说明：CSD 是 FID 单通道数据类型，不是扩展名。.ocb 是本工作站固有色谱格式（与已能打开的农药残留样同格式）。这不是厂商实机原始文件，仅供软件流程演示。

方法约定（与插件默认值一致）
  内标：乙酸正丁酯  贮备液 17.6 g/L
  加标：样品 1.00 mL + 内标 0.10 mL  → 进样内标浓度 1.6000 g/L
  本机 RT = 厂商参考 RT + 0.055 min（默认 ±0.15 min 窗口内）
  柱：XP-白酒 C2，30 m × 0.32 mm × 1.00 μm
  采样：20 Hz，0–19 min，共 16 个峰
  定稿方法包：demo/nongxiang-fid-default.bjm（浓香FID默认方法.bjm）

操作步骤

A. 打开混标并出峰
  1. 工作站主窗体（不是控制面板）：文件 → 打开 CSD 文件
     没有类型下拉框。留在「用户位置」，展开：E: → OpenChrom → baijiu-demo
     应能看到 mix-15plus-istd.ocb 与 sample-nongxiang.ocb（及中文同名文件）
     点文件本身，红字「请至少选择一个有效的选项」消失后点「完成」
  2. 确认谱图上 2–17 min 有 16 个峰
  3. 插件 → 白酒分析（默认已加载浓香 FID 方法：内标乙酸正丁酯 17.6 g/L，加标 1.00+0.10 mL，RT 窗口 ±0.15 min）
  4. 点「推荐积分」（一阶导数阈值 MEDIUM + 梯形积分，演示混标约 16 个峰）
     也可仍走：色谱 → 峰检测 → 一阶导数；色谱 → 峰积分 → 峰梯形积分器
  5. 左侧「峰/扫描」列表应约 16 个峰，且面积不为 0；「峰匹配」页可查看未匹配峰并手动指定
  6. 确认内标体积与贮备液为默认值，点「用当前谱图做校正」
     或「多点校正」页「演示三点」（同谱图 0.5/1.0/1.5，见 操作步骤.txt 节 I）
  7. 到「组分方法」页，应看到本机 RT 和 RF 已写入；可改 RT / 窗口 / 是否定量 / 是否甲醇判定后点「应用选中行」，再另存为厂方法 *.bjm
     误改后可点「加载默认浓香方法包」恢复 XP-C2 + 乙酸正丁酯 + 15 混标及上述四项默认（会清除 RF 与多点校正点）
     演示文件：demo/nongxiang-fid-default.bjm（浓香FID默认方法.bjm）

B. 打开样品并定量
  1. 同样打开样品 .ocb，点「推荐积分」（或先一阶导数峰检测，再峰梯形积分）
  2. 插件 → 白酒分析，填写：
       样品编号  LD-BJ-001
       酒名  模拟浓香（演示）
       批号  演示批
       香型  浓香
       酒精度  52
       检测人  演示
       甲醇限量原料  粮谷酿造
  3. 点「定量并写回峰表」
     必须已完成 A 步混标校正。未校正或 RF 无效时会阻止定量（中英提示），不会写出含量或 GB 2757。
  4. 点「预览/打印报告」（须定量成功）。字段与打印/CSV 见 操作步骤.txt 节 J

  测得甲醇  0.180 g/L
  折算 100%vol  0.3462 g/L
  限量  0.6 g/L  → 合格
  折算公式：测得甲醇(g/L) × 100 / 酒精度(%vol)
  限量来源：厂方法/偏好设置（baijiu-defaults.properties / *.bjm），不写死在判定逻辑中

C. Week 2 白酒工作台（可选）
  1. 窗口 → 视角 → 白酒工作台（或 插件 → 白酒工作台 → 切换白酒工作台）
     右侧为日常按钮：打开色谱图、推荐积分、白酒分析、报告
     研究类峰检测/积分仍在「色谱」菜单，不删除
  2. 熟练操作员可继续直接用「白酒分析」；新操作员可用「三步向导」
     ① 方法/样品  ② 谱图处理（推荐积分）  ③ 结果与报告
  3. 报告窗口：打印 / 另存为 PDF、保存 HTML、导出 CSV / Excel(CSV)
  4. 简单批量：插件 → 白酒工作台 → 简单批量
     多选 .ocb → 同一方法 → 样品×组分汇总表 → 导出 CSV
     相同样品编号的两行会作为平行样显示均值与相对偏差
     不是复杂进样序列调度
  5. 批处理结果：插件 → 白酒工作台 → 批处理结果
     按进样序列每一针一行。离线打开 demo/sequence-batch-results.json
     （先改 chromatogramPath 到本机 demo .ocb）。详见 操作步骤.txt 节 F
  6. 平行样：插件 → 白酒工作台 → 平行样
     针 A / 针 B 各选 .ocb（演示可两次选 sample-nongxiang.ocb）
     相对偏差 % = |针A − 针B| / 均值 × 100%

回归检查清单（演示文件）
  □ 打开 mix-15plus-istd.ocb 或 sample-nongxiang.ocb
  □ 推荐积分后峰数约 16（2–17 min）
  □ 峰匹配页能看到内标 乙酸正丁酯（约 10.382 min），面积不为 0
  □ 样品页填写酒精度 52、原料 粮谷酿造，定量后甲醇约 0.180 g/L
  □ GB 2757 面板显示：测得甲醇、折算说明、限量来源、判定「合格」
  □ 预览/打印报告能打开，含样品信息、方法摘要、结果表、GB 判定、谱图缩略、操作者与时间（节 J）
  □ 导出 CSV / Excel(CSV) 能用 Excel 打开，列含检测人、检测日期、超限、免责声明
  □ 另存厂方法 *.bjm 后再加载，柱/内标/15 混标/RT/窗宽/是否定量/是否甲醇判定一致；「加载默认浓香方法包」可恢复（会清 RF 与多点校正点）
  □ 多点校正：演示三点后甲醇与主酯有 R²，拟合 RF 仍能定量样品

实机点火后如何进入同一白酒路径（不绑定仪器反控）
  点火、进样、采集由仪器侧完成。本插件不控制气路/点火/采集。
  采集结束后，把得到的色谱文件保存为本工作站可打开的格式（优先 .ocb，
  或先用「文件 → 打开 CSD 文件」能打开的厂商/交换格式），再走与演示相同的入口：
    打开色谱图对象 → 推荐积分 → 白酒分析 → 定量 → GB 2757 → 报告
  只要工作站里已经有一张打开的 FID（CSD）色谱图，白酒分析读的就是这张图，
  与文件来自演示目录还是实机采集无关。
