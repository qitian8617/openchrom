白酒演示回归检查清单（Week 2）

厂里操作员请先读 docs/白酒FID试点操作手册.md。
本清单是功能 1～14 的工程回归勾选，不是现场验收剧本。
现场项 16（真混标 / 合格 / 不合格各一遍）：docs/白酒FID试点演示与验收脚本.md
打印勾选：demo/验收勾选表.txt。项 15（驻场）不在本清单。

演示文件（不在 git，本地 OpenChrom-week1-ws / E:\OpenChrom\baijiu-demo）
  mix-15plus-istd.ocb（或 白酒混标_15组分加内标.ocb）
  sample-nongxiang.ocb（或 白酒样品_浓香模拟.ocb）

检查项
  1. 峰数
     打开混标或样品 → 白酒工作台「推荐积分」或分析窗「推荐积分」
     2–17 min 约 16 个峰（随包演示 .ocb 仍按旧库，含约 16.555 min 多余峰），面积不为 0
  2. 内标
     默认方法：乙酸正丁酯，本机 RT 10.582 min（厂商 10.527 + 0.055）
     随包演示谱图内标峰仍约 10.382 min，与 ±0.15 min 窗口对不上。重载默认方法后须复核，或改本机 RT / 手动指定
     进样内标浓度默认 1.6000 g/L（贮备液 17.6 g/L × 0.10 / 1.10）。15 种混标中乙酸正丁酯为 0.3632 g/L，只用于校正瓶，不代替样品加标
  3. 甲醇 GB 2757
     样品编号 LD-BJ-001，酒精度 52，原料 粮谷酿造
     定量后测得甲醇约 0.180 g/L
     折算 100%vol ≈ 0.3462 g/L，限量 0.6 g/L（来自厂方法/偏好，非 Java 写死）
     判定「合格」，面板同时显示测得值、折算公式、限量来源/标准版本
  4. 报告（定稿）
     「预览/打印报告」打开 HTML（须先定量成功；未校正被门闩拦住）
     含样品信息（编号/酒名/批号/香型/酒精度/原料/检测人/检测日期）、方法摘要（方法名/柱/内标/程序升温/加标）、
     谱图缩略、结果表（组分/RT/峰面积/RF/含量 g/L/超限/备注）、GB 2757（合格/不合格/无法判定 + 折算说明）、
     操作者与时间（检测人/检测日期/报告生成时间）
     免责：不声明执行 GB 5009.266
     「打印 / 另存为 PDF」走系统打印对话框
     「导出 CSV」无 BOM、「导出 Excel(CSV)」带 BOM，列与 HTML 对齐，Excel 可打开
     详见 docs/GCWS-REPORT.md；操作步骤节 J
  5. 混标校正门闩
     不先做混标校正（或甲醇 RF 为 NaN/0/超范围）时，定量被阻止，提示先「用当前谱图做校正」
     校正有效时，演示样品仍为甲醇约 0.180 g/L、GB 2757 合格
     加载默认浓香方法包会清除 RF，不能用来绕过门闩
  6. 浓香默认方法包
     白酒分析「加载默认浓香方法包」恢复 XP-C2 + 乙酸正丁酯 + 15 混标（含是否定量/是否甲醇判定默认）
     「另存厂方法」后再「加载厂方法」，柱/内标/混标浓度/RT/窗宽/定量与甲醇判定标志一致；有 RF 时定量仍可用
     演示文件 demo/nongxiang-fid-default.bjm（浓香FID默认方法.bjm）
  7. 组分库可编辑
     组分方法页可改本机 RT、窗口、是否定量、是否甲醇判定，保存方法/另存厂方法后往返
     不定定量不写含量但仍匹配出峰；取消甲醇判定则跳过 GB 2757（不把缺甲醇当成未检出）
     「加载默认浓香方法包」把四项恢复为目录默认。详见 docs/GCWS-COMPOUND-LIBRARY.md
  8. 平行样
     进样序列「添加平行样」后同一编号两针；或工作台「平行样」两次选择 sample-nongxiang.ocb
     表中甲醇（重点）有均值与相对偏差 %；公式见 docs/GCWS-PARALLEL.md
     未校正时不会绕过门闩、不会发明含量
  9. 批处理结果
     进样序列「生成结果表」或工作台「批处理结果」
     离线：打开 demo/sequence-batch-results.json（先把 chromatogramPath 改到本机 demo .ocb）
     已完成且文件存在的行有甲醇等含量与样品 GB 2757；待进样/已跳过行仍在表中并写明原因
     未校正时样品行无含量。简单批量（任选 .ocb）仍可用
  10. 多点校正 + R²
     白酒分析「多点校正」：演示三点（同谱图 0.5/1.0/1.5）后甲醇与主酯有 R²
     拟合写入有效 RF，样品定量与门闩仍可用；「用当前谱图做校正」单点仍可用
     公式见 docs/GCWS-MULTIPOINT.md
  11. 报告定稿
     定量后预览含节 J 所列字段；CSV 含检测人/检测日期/超限/GB 判定/免责声明
     多点拟合后报告 RF 与定量所用有效 RF 一致（可有「多点拟合有效RF」备注）
     未校正不能打开报告。JavaSE-21。无 Part 11 / LIMS / GB 5009.266 声明
  12. 安装 / 许可
     按 docs/GCWS-INSTALL.md 导出 Baijiu FID Pilot 到文件夹，Install New Software 装到社区版
     About / Installation Details 可见 1.6.32.*；白酒工作台能打开
     未授权：仍可打开谱图；定量/报告中英阻止。导入 demo/sample-pilot.bjlic 后状态「有效」
     操作步骤节 K。不重编整个 community 产品。无加密狗 / 在线激活 / Part 11
  13. 中文操作手册
     docs/白酒FID试点操作手册.md 覆盖开箱→报告与常见故障（装不上 feature、许可、未校正、峰数、RF/R²、报告、Java/BREE、FID 未就绪、谱图打不开）
     demo/README.txt 与 操作步骤.txt 节 L 指向该手册。英文仅 docs/GCWS-OPERATOR-MANUAL.md 指针。无 GB 5009.266 / Part 11 / LIMS 声明
  14. 现场演示与验收脚本（项 16，非本回归代替）
     docs/白酒FID试点演示与验收脚本.md 含脚本 A（无真机：混标→合格→仅演示不合格）与脚本 B（真混标/合格/不合格各一针）
     软件不合格：临时粮谷限量 0.30，须恢复 0.6；短步骤 demo/仅演示-不合格限量.txt
     操作步骤节 M；demo/验收勾选表.txt。不改出厂 GB 2757 默认。无 GB 5009.266 / Part 11 / LIMS
